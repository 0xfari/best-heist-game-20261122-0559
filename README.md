The Velvet Vault — a top-down museum heist game. Sneak past three patrolling guards and two sweeping cameras, cut the cameras at the fuse box, toss coins to pull guards away, steal the Sunburst Diamond from its case, and get back out the door before dawn. Keyboard and mouse, no build step, no network: plain static files under game/.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
